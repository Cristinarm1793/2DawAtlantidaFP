Para añadir una receta, copia la estructura de una entrada existente del JSON y modifica todos sus datos. El índice completo se genera automáticamente. Las imágenes se encuentran en assets/img/recetario; revisar nombre exacto, fuente y licencia. Los campos y su presentación se gestionan en js/recetario.js.
