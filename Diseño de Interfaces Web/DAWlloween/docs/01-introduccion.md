# 1. Introducción

## 1.1. Descripción del proyecto

**DAWlloween** es un proyecto web interactivo desarrollado con motivo de Halloween, cuyo objetivo es combinar el diseño de interfaces, la programación y la creatividad para ofrecer una experiencia de navegación diferente.

La página estará ambientada en el terror, tomando como inspiración las casas abandonadas, los objetos malditos y los videojuegos de terror retro.

El proyecto se organizará en diferentes secciones, cada una con una temática y unas funcionalidades propias. La página principal representará un museo de objetos malditos, mientras que las demás secciones permitirán consultar recetas de Halloween, participar en una aventura de texto, conocer información sobre el proyecto y utilizar un formulario de contacto.

Además, se incorporará un sistema de registro e inicio de sesión para trabajar con formularios y sesiones mediante PHP.

## 1.2. Objetivos

El objetivo principal de DAWlloween es desarrollar una página web funcional, interactiva y ambientada en Halloween, aplicando los conocimientos adquiridos durante el segundo curso de Desarrollo de Aplicaciones Web (DAW).

Los objetivos específicos son:

- Diseñar una interfaz visualmente atractiva y relacionada con la temática de terror.
- Mantener una navegación intuitiva y accesible para el usuario.
- Aplicar HTML y CSS para estructurar y diseñar las diferentes páginas.
- Utilizar JavaScript para crear interacciones y desarrollar un minijuego.
- Implementar formularios y gestionar sesiones de usuario mediante PHP.
- Configurar un servidor web Apache para ejecutar el proyecto en un entorno local.
- Documentar el diseño, funcionamiento y despliegue de la aplicación.

## 1.3. Funcionalidades previstas

DAWlloween contará con las siguientes secciones y funcionalidades:

| Sección                       | Funcionalidades previstas                                                                                                   |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| **Inicio — Museo del horror** | Exposición de objetos malditos con comportamientos interactivos, anomalías visuales y un botón para restablecerlas.         |
| **Recetario**                 | Libro de recetas de Halloween con navegación entre recetas, ingredientes e instrucciones.                                   |
| **No entres — Juego**         | Aventura de texto inspirada en los videojuegos clásicos, en la que el usuario podrá introducir comandos y tomar decisiones. |
| **Sobre nosotros**            | Presentación del proyecto, información sobre su creación, referencias utilizadas y elementos interactivos.                  |
| **Contacto**                  | Formulario para enviar un mensaje dirigido a Jack Skellington.                                                              |
| **Registro**                  | Formulario para registrar usuarios con nombre, contraseña, correo electrónico y pregunta de seguridad.                      |
| **Inicio de sesión**          | Acceso mediante las credenciales del usuario registrado.                                                                    |
| **Cambio de contraseña**      | Recuperación o modificación de contraseña mediante una pregunta de seguridad.                                               |

Algunas secciones incluirán efectos visuales y comportamientos inesperados relacionados con el terror. Estas interacciones se diseñarán procurando que no dificulten las funciones principales de la página.

## 1.4. Tecnologías utilizadas

Para desarrollar DAWlloween se utilizarán las siguientes tecnologías:

| Tecnología     | Aplicación                                                                      |
| -------------- | ------------------------------------------------------------------------------- |
| **HTML5**      | Estructura y contenido de las páginas web.                                      |
| **CSS3**       | Diseño visual, estilos, distribución de elementos y efectos.                    |
| **JavaScript** | Interactividad, manipulación del DOM y funcionamiento del minijuego.            |
| **PHP**        | Procesamiento de formularios, registro, inicio de sesión y gestión de sesiones. |
| **Apache**     | Servidor web utilizado para ejecutar el proyecto en un entorno local.           |
| **Markdown**   | Elaboración de la documentación del proyecto.                                   |

## 1.5. Organización del proyecto

El proyecto estará organizado en diferentes carpetas y archivos para separar el contenido, los estilos, los scripts y la documentación.

La carpeta `docs` contendrá los documentos principales:

| Documento            | Contenido                                                                |
| -------------------- | ------------------------------------------------------------------------ |
| `01-introduccion.md` | Presentación, objetivos, funcionalidades y tecnologías del proyecto.     |
| `02-diseno.md`       | Sitemap, labelling, wireframes y guía de estilo visual.                  |
| `03-guia-usuario.md` | Instrucciones para utilizar las diferentes funcionalidades de la web.    |
| `04-despliegue.md`   | Configuración del servidor y pasos necesarios para ejecutar el proyecto. |

La estructura definitiva de carpetas y archivos se concretará durante el desarrollo.
